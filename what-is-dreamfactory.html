How It Works

Database to API in 3 Steps

No code required. No months of development. Just connect and go.

1

Connect Your Database

Provide your database connection details — SQL Server, PostgreSQL, MySQL, Oracle, Snowflake, MongoDB, or any of 50+ supported sources. DreamFactory automatically introspects your schema.

2

Configure Access Controls

Set up role-based access controls, API keys, rate limits, and field-level security through the visual admin console. Define exactly who can access what.

Deploy Your APIs

FAQ

Frequently Asked Questions

What is DreamFactory?

DreamFactory is a self-hosted API generation platform. You connect it to any SQL or NoSQL database, and it automatically generates production-ready REST APIs with full CRUD operations, stored procedure endpoints, and OpenAPI documentation. No code required.

How is DreamFactory different from building APIs manually?

Building REST APIs by hand typically takes weeks per database and requires ongoing maintenance. DreamFactory generates complete APIs in minutes with built-in security, documentation, and governance — eliminating months of boilerplate code.

Is DreamFactory free?

The DreamFactory open-source edition is free and includes PostgreSQL support. Commercial editions add 50+ additional database connectors, priority support, and enterprise features like LDAP/AD integration.

Where does DreamFactory run?

DreamFactory is self-hosted — it runs on your infrastructure. Deploy on Linux, Docker, Kubernetes, or directly within Snowflake as a Native App. Your data never leaves your environment.

Can DreamFactory work with AI agents?

Yes. DreamFactory generates standard REST APIs that any AI agent can consume. It also supports MCP (Model Context Protocol) for native AI assistant integration. AI agents get governed data access without database credentials.

How long does it take to set up?

Docker deployments take under 5 minutes. Most teams have their first API generated within 30 minutes of installation.
