FAQ

Manufacturing FAQ

Can DreamFactory connect to SAP databases?

Yes. DreamFactory can connect to the underlying SAP database (HANA, Oracle, SQL Server, or DB2) and generate REST APIs for direct data access. This complements SAP's own APIs by providing governed access to custom tables and views.

Does DreamFactory work in air-gapped environments?

Yes. DreamFactory is self-hosted and can be deployed in fully air-gapped networks. No internet connectivity required after installation.

How does DreamFactory handle OT/IT convergence?

DreamFactory bridges OT and IT by providing governed API access to databases on both sides. Factory floor data in SQL Server or time-series databases becomes accessible to enterprise applications through secure REST APIs.
