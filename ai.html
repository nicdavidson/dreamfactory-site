FAQ

AI Data Gateway Questions

How does DreamFactory secure AI agent access to databases?

DreamFactory acts as a governed middleware layer. AI agents authenticate with API keys that are bound to specific roles. Each role defines exactly which tables, fields, and operations are allowed. The AI agent never sees database credentials.

What AI platforms does DreamFactory work with?

DreamFactory generates standard REST APIs that work with any AI platform — OpenAI, Anthropic Claude, Google Gemini, open-source models, and custom AI applications. The MCP server support adds native integration for compatible AI assistants.

Do I need to move my data to use DreamFactory with AI?

No. DreamFactory connects to your databases where they are. Your data stays in your infrastructure. The AI agent accesses it through governed API calls — no ETL, no data copying, no new data stores.
