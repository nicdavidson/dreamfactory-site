Self-Hosted

Your Infrastructure. Your Data.

Deploy DreamFactory on your own servers, your cloud, or your air-gapped network. Zero data leaves your environment. Zero vendor lock-in.

Portable & Stateless

DreamFactory runs as a stateless application. Deploy on bare metal, VMs, containers, or Kubernetes. Move between environments without reconfiguration.

Governed API Publishing

Control exactly which database tables, views, and stored procedures are exposed as API endpoints. Publish only what your consumers need.

Admin Console

Visual admin interface for managing database connections, API keys, roles, and access controls. No command-line required for day-to-day operations.

API Generation

Connect to 50+ Databases Instantly

Point DreamFactory at any supported database and generate a full REST API with endpoints for every table, view, and stored procedure. Production-ready in minutes, not months.

Database Support

SQL Server, PostgreSQL, MySQL, Oracle, Snowflake, MongoDB, DynamoDB, IBM DB2, SAP HANA, and 40+ more. If you have a database, we have a connector.

Production-Ready in Minutes

Auto-generated REST endpoints with pagination, filtering, sorting, and related record lookups. No boilerplate code to write or maintain.

Unlimited API Creation

Connect as many databases as you need. Each gets its own namespace, its own access controls, and its own auto-generated documentation.

Auto-Generated OpenAPI Documentation

Every API comes with a complete OpenAPI/Swagger specification. Import directly into Postman, generate client SDKs, or browse interactive docs.

Security & Governance

Federated Access and Data Governance

Enterprise-grade security built in. Role-based access controls, API key management, complete audit logging, and field-level security — all without writing code.

Access Control & Compliance

Support for HIPAA, SOC 2, GDPR, and PCI-DSS compliance requirements. Self-hosted deployment means your data never leaves your control.

Complete Audit Logging

Every API call is logged with user identity, timestamp, request details, and response status. Export to your SIEM or log management platform.

Role-Based Access Controls

Define granular permissions per role: which endpoints, which HTTP methods, which fields, and which records each role can access.

API Key Management

Generate, rotate, and revoke API keys through the admin console. Set per-key rate limits and associate keys with specific roles.

Customization

Server-Side Scripting & Business Logic

Extend auto-generated APIs with custom business logic using pre- and post-process scripts. Write in Node.js, PHP, or Python — no separate microservice needed.

Pre/Post-Process Scripts

Intercept any API request before it hits the database or after the response is generated. Validate inputs, transform outputs, enforce business rules.

Multiple Script Engines

Write scripts in Node.js, PHP, Python, or V8JS. Use whichever language your team knows best.

SOAP to REST Conversion

Point DreamFactory at any WSDL endpoint and auto-generate modern REST/JSON APIs from legacy SOAP services. No SOAP service changes required.

FAQ

Frequently Asked Questions

How long does it take to set up DreamFactory?

Most teams have DreamFactory installed and their first API generated within 30 minutes. Docker deployments take under 5 minutes.

Do I need to write any code?

No. DreamFactory auto-generates REST APIs from your database schema. You can optionally add custom business logic with server-side scripts, but it's not required.

How does DreamFactory handle database schema changes?

DreamFactory introspects your database schema on each request. When you add tables, views, or stored procedures, new API endpoints appear automatically.

Can I use DreamFactory with multiple databases?

Yes. Connect as many databases as you need — even different database types. Each gets its own API namespace and access controls.

Is DreamFactory open source?

Yes. The core DreamFactory platform is open source with PostgreSQL support. Commercial editions add 50+ additional connectors, priority support, and enterprise features.
